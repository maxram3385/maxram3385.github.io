# Personal Portfolio Homepage

This is a cumulative portfolio project created while learning web development and programming using JavaScript, HTML, and CSS. The page introduces me, lists some of my skills, displays projects I have completed, and provides a contact form with dynamic feedback.

The Projects section uses JavaScript objects to store each project's title, summary, image, and repository link. The objects are placed in an array, saved in session storage, and displayed dynamically on the page.

## Features

* Welcome modal
* About and skills sections
* Dynamically generated project list
* Project information saved in session storage
* Dark mode preference saved in local storage
* Contact form with a tooltip and confirmation message

## Languages and Libraries

* HTML
* CSS
* JavaScript
* JavaScript DOM methods
* Browser session storage and local storage

No external libraries or frameworks are required. Everything is handled using built-in browser features.

## Dependencies

There are no dependencies to download or install. A modern web browser with JavaScript enabled will run the page with full functionality.

## Running the Page

Keep `index.html` and the project image files in the same folder so the images display correctly. Open `index.html` directly in a web browser or run the page through a local server such as XAMPP.
